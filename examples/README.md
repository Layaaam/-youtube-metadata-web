# Examples

Sample output from the standalone CLI script (`scripts/youtube_metadata.py`),
kept here as evidence of Part 1 working end-to-end.

| File | Generated by |
|---|---|
| `my_video.json` | `python youtube_metadata.py <url> --save` |
| `zw47_q9wbBE_metadata.json` | `python youtube_metadata.py "https://www.youtube.com/watch?v=zw47_q9wbBE" --save` |

These are just saved JSON output, not code — they're not used by the app at
runtime. To regenerate them yourself:

```bash
cd scripts
python youtube_metadata.py "https://www.youtube.com/watch?v=VIDEO_ID" --save
```
